# UI

This section explains how to use the website from the sidebar and canvas controls. Use these pages when you want to run the simulation, edit the grid, configure rules, inspect metrics, or export data.

## Pages

- [Playback](Playback): run, pause, step, step back, and restart the simulation.
- [Speed](Speed): choose target speed, max speed, recording, and live metrics.
- [Draw tribe](Draw-Tribe): choose brush behavior and which tribes are drawn.
- [Grid size](Grid-Size): resize the simulation grid, choose topology, and read frame-size limits.
- [Packing](Packing): choose how many bits are used for each cell.
- [Presets](Presets): load built-in ruleset examples.
- [Tribes](Tribes): add, rename, recolor, mute, or remove tribes.
- [Rules](Rules): configure the rules that drive cell evolution.
- [Metrics](Metrics): inspect live population, diversity, and interface metrics.
- [Download](Download): export recorded simulation data.
- [Snapshot](Snapshot): save or load `.golt` snapshot files.
- [Shortcuts](Shortcuts): use keyboard and pointer controls on desktop.
